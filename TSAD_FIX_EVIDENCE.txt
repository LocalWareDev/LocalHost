TSAD (0x60) fix - evidence captured 2026-08-29
==============================================

ROOT CAUSE: the RTL8139 driver polls TSAD (0x60, Transmit Status of All
Descriptors) to learn which sends completed. We set completion only in the
per-descriptor TSD regs (0x10/0x14/0x18/0x1C) and never wrote 0x60, so it read
0x0000 = 'nothing ever completed'. After ~23s the driver declared the
transmitter hung and reset the adapter; each reset discarded in-flight RX,
freezing guestAcked at ISN+1.

BLIND SPOT: BAR1 is mapped WHvMapGpaRangeFlagRead and rtl8139Regs IS the mapped
page, so register READS run natively and never trap. Registers the driver only
reads are invisible in every log. Two root causes hid there: BMSR (0x64) and
TSAD (0x60).
